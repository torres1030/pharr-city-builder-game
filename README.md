# pharr-city-builder-game
Intaractive quiz game for deployment of the Pharr Way

Help Cody, Buddy, Rigs, and Dug build the City of Pharr. Answer Pharr Way questions in order to score and build the city! The more questions you answer correct, the higher of a score you get. Work together and see who gets the most points! If you fail to answer a question correctly, your building will get cited for review. If you fail to build the entire city, the highest scoring player wins!
